# Legacy Hotkeys Reference (AHK)

Questa reference conserva le scorciatoie storiche del sistema AHK per facilitarne il riuso in template, test e documentazione del framework attuale.

## Globali (storico)

- `^+F1`: toggle script
- `^+I`: modalita intensa
- `^F5` / `+F5`: reload
- `+F12`: toggle suoni
- `^+F12`: toggle voce
- `^+F10`: toggle debug
- `^+F9`: switch NVDA/SAPI
- `+H`, `^H`, `^+H`, `!H`: help/sintesi
- `^+F8`: info script
- `^+Esc`: reset input emergenza

## CK3 specifiche (storico)

- `+F1`, `+F2`: navigazione pagine
- `\\`, `,`, `^,`, `+,`, `.`: OCR/click/routing
- `-`, `^\\`, `^Enter`: click o invio sul cursore NVDA
- `^+c`, `^+d`, `^d`: utility cursore
- `+1`, `^2`, `+3`: azioni rapide al centro
- `^g`: selezione armate
- `^+p`: pausa + OCR
- `^CapsLock`, `^Insert`, `^NumpadIns`: selezione tasto NVDA

## Nota di integrazione

Le hotkey sopra non sono runtime attivo nel repository corrente: vanno usate come base di conversione verso template e addon NVDA nel framework moderno.
